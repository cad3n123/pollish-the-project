# Slideshow Website

This project displays a simple slideshow of images using HTML, CSS, and JavaScript. To enable basic progressive enhancement, the script replaces the `no-js` class on the `<html>` element with `js`.

## Bitly flagging

If a link to this site is shortened with Bitly and gets flagged, ensure the content description is clear. The page now includes a descriptive meta tag to better identify its purpose. If issues persist, contact Bitly support for further review.
